# FPGA 기반 기억력 게임

Verilog HDL로 LED 패턴을 기억하고 재입력하는 게임을 구현한 FPGA 프로젝트입니다. 게임 진행을 유한 상태 머신(FSM)으로 구성하고, LED·버튼·LCD·7-Segment·도트 매트릭스·부저·모터를 하나의 시스템으로 연동했습니다.

## 프로젝트 목적

게임 규칙을 하드웨어 로직으로 구현하면서 상태 전환, 클록 기반 타이밍 제어, 입력 처리, 주변장치 인터페이스 설계를 다루는 것을 목표로 했습니다.

## 주요 기능

- **패턴 생성**: 16비트 LFSR을 이용한 의사난수 기반 3단계 LED 패턴 생성
- **정답 판별**: 사용자가 입력한 버튼 순서와 생성 패턴 비교
- **4단계 난이도**: Easy·Normal·Hard·Very Hard에 따라 패턴 표시 시간 변경
- **힌트 기능**: 입력 중 모드 스위치를 조작하면 패턴 다시 표시
- **입력 중복 억제**: 키 변화 감지와 대기 상태를 통한 연속 입력 처리
- **게임 피드백**: 점수 및 성공·실패 상태를 LCD와 LED에 표시
- **주변장치 연동**: 7-Segment 시간 표시, 도트 매트릭스 출력, 부저 및 모터 제어

## 시스템 구성

사용자 입력 → 게임 FSM → 패턴 표시 및 정답 판별 → 점수·상태 갱신 → 주변장치 출력

12MHz 입력 클록을 PLL로 24MHz로 변환하고, 카운터를 이용해 각 동작의 시간을 제어합니다.

## 기술적 구현

### FSM 기반 게임 제어

대기, 패턴 생성, 패턴 표시, 입력 대기, 정답 확인, 성공 및 실패 상태를 구분했습니다. 상태별 출력과 전환 조건을 정의해 게임 진행과 주변장치 동작을 연결했습니다.

### LFSR 기반 패턴 생성

시프트 레지스터와 XOR 피드백으로 의사난수를 생성하고, 일부 비트를 LED 인덱스로 사용했습니다.

### 모듈 단위 하드웨어 구성

게임 로직과 표시·구동 장치를 개별 Verilog 모듈로 분리하고, 최상위 모듈에서 공통 클록과 게임 상태 신호로 연결했습니다.

## 기술 스택

- Verilog HDL
- Xilinx ISE 14.7
- PLL IP
- FPGA 디지털 입출력 및 주변장치 제어

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `top.v` | 전체 모듈 연결 및 클록 구성 |
| `led_ctrl.v` | 패턴 생성, 게임 FSM, 입력 판별, 점수 처리 |
| `segment.v` | 시간 카운터 및 7-Segment 출력 |
| `textlcd.v` | LCD 점수 및 상태 표시 |
| `dot.v` | 도트 매트릭스 출력 |
| `piezo.v` | 부저 제어 |
| `motor.v` | 모터 제어 |
| `top.ucf` | FPGA 핀 및 타이밍 제약 |

## 실행 방법

1. Xilinx ISE에서 `project.xise`를 엽니다.
2. 사용하는 FPGA 보드와 `top.ucf`의 핀 할당을 확인합니다.
3. 합성 및 구현을 진행하고 Bitstream을 생성합니다.
4. FPGA에 다운로드한 뒤 난이도 입력으로 게임을 시작합니다.
5. LED 패턴을 기억하고 대응하는 버튼을 순서대로 입력합니다.

## 프로젝트에서 다룬 역량

- FSM 기반 순차회로 설계
- 클록·카운터를 활용한 동작 시간 제어
- 의사난수 생성 및 입력 이벤트 처리
- 여러 주변장치의 모듈화와 통합
